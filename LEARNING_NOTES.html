1. Foundations of Artificial Intelligence & Machine Learning

What is Artificial Intelligence?

Artificial Intelligence (AI) refers to the computational systems and algorithms engineered to perform cognitive tasks that historically required human intelligence. These tasks include perception, linguistic reasoning, pattern extraction, decision-making, and autonomous problem-solving.

  • Narrow AI (Weak AI): Specialized systems designed to excel at a singular, well-defined task (e.g., Apple Siri, Tesla Autopilot, AlphaGo, Spam filters). All currently deployed AI systems represent Narrow AI.
  • General AI (AGI): Theoretical systems with human-grade generalized reasoning across diverse domains without requiring task-specific retraining.

What is Machine Learning?

Machine Learning is a subset of AI that provides systems the capability to learn and optimize performance from empirical data without being explicitly hand-coded with procedural rules.

"A computer program is said to learn from experience E with respect to some task T and performance measure P, if its performance on T, as measured by P, improves with experience E." — Tom Mitchell (1997)

The Paradigm Shift

  • Traditional Programming: Data + Explicit Rules => Output / Answers
  • Machine Learning: Data + Answers => Learned Rules / Model

2. Hierarchy: AI vs Machine Learning vs Deep Learning

Dimension Artificial Intelligence (AI) Machine Learning (ML) Deep Learning (DL)
Scope Broad umbrella of all intelligent systems Subset of AI learning from empirical data Subset of ML utilizing multi-layered neural networks
Feature Extraction Handcrafted heuristics and rules Manual feature engineering by data scientists Automatic hierarchical representation learning
Data Dependency Can run on small rule bases Medium structured tabular datasets Large-scale unstructured data (images, text, audio)
Hardware Standard CPU Standard CPU / optional GPU High-performance parallel GPUs / TPUs
Primary Examples A* Search, Rule-based Chatbots, Expert Systems Random Forest, SVM, Logistic Regression Transformers (GPT, Gemini), CNNs (ResNet)

3. Real-World Applications of AI

  • Healthcare: Deep learning CNNs detecting tumors and anomalies in MRI/CT scans with radiologist-level accuracy; AlphaFold predicting 3D protein structures.
  • Autonomous Systems: Sensor fusion combining LiDAR, radar, and camera streams to execute real-time object classification and path planning.
  • Finance & Security: Real-time anomaly detection screening transaction flows to identify credit card fraud; high-frequency algorithmic market analysis.
  • Natural Language Processing (NLP): Large Language Models (LLMs) executing multi-turn reasoning, translation, and code synthesis.
